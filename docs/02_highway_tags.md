# highwayタグ体系

`highway`タグはOSMにおける道路分類の中核。**物理的な特性ではなく、道路ネットワークにおける重要度（機能的重要性）**で分類される。

## 主要道路

重要度の降順:

| タグ値 | 定義 | 日本での対応 |
|--------|------|-------------|
| `motorway` | 自動車専用道路（アクセス制限・中央分離帯あり） | 高速自動車国道（東名、名神等） |
| `trunk` | motorwayに次ぐ最重要道路 | 一般国道（国道1号、国道246号等） |
| `primary` | 大きな町を結ぶ重要道路 | 主要地方道（六角形のヘキサ標識） |
| `secondary` | 町と町を結ぶ道路 | 一般都道府県道 |
| `tertiary` | 小さな町や村を結ぶ道路 | 市町村道の主要なもの |
| `unclassified` | 通過機能を持つ最低ランクの道路 | 市町村道（1車線） |
| `residential` | 住宅地域のアクセス道路 | 住宅地内の生活道路 |

※各レベルに `_link` 付きのランプ・連絡路がある（例: `motorway_link`）

## 特殊道路

| タグ値 | 用途 | 日本での対応 |
|--------|------|-------------|
| `service` | 敷地内道路（駐車場、私道等） | 駐車場内通路、私道 |
| `living_street` | 歩行者優先の道路 | コミュニティ道路 |
| `pedestrian` | 歩行者専用道路 | 歩行者天国、商店街 |
| `track` | 農道・林道 | 農道、林道 |

## 歩行者・非自動車道

| タグ値 | 用途 |
|--------|------|
| `footway` | 歩道・遊歩道 |
| `cycleway` | 自転車道 |
| `path` | 一般的な小道（複数用途） |
| `steps` | 階段 |

## 一方通行（oneway）

| 値 | 意味 |
|----|------|
| `oneway=yes` | 一方通行（ウェイの描画方向が進行方向） |
| `oneway=no` | 双方向通行（明示的に上書き） |
| `oneway=-1` | ウェイの描画方向と逆方向が進行方向 |

- 方向はウェイを構成するノードの**順序**で決まる
- `motorway`と`motorway_link`は暗黙的に`oneway=yes`

## シミュレーションで使うタグ

本プロジェクトでは以下のhighwayタグの道路を取得対象にしている:

```
residential, tertiary, secondary, primary, trunk,
unclassified, living_street, pedestrian, footway, path, service
```

`motorway`は歩行者が通行できないため除外。
