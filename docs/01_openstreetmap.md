# OpenStreetMap 概要

## OpenStreetMapとは

OpenStreetMap（OSM）は、2004年にイギリスで設立された、誰でも自由に編集・利用できるオープンな世界地図プロジェクト。「地図のWikipedia」とも呼ばれ、世界中のボランティアがGPS端末、航空写真などを元に地図データを作成・更新している。

- 登録ユーザー数: 約1,000万人（2025年時点）
- 運営: OpenStreetMap Foundation（OSMF、イギリスの非営利団体）
- 日本チャプター: 一般社団法人オープンストリートマップ・ファウンデーション・ジャパン（OSMFJ）

## データモデル

OSMのデータは3つの基本要素（Element）とタグで構成される。

### Node（ノード）
- 緯度・経度の座標を持つ**点データ**
- 一意のIDと座標（lat, lon）を持つ
- 単独でバス停や信号機などを表現可能
- 多くはWayの構成要素（頂点）として機能

### Way（ウェイ）
- ノードの順序付きリストで構成される**線データ**または**面データ**
- 道路・河川 → 「開いたウェイ（open way）」
- 建物・森林 → 「閉じたウェイ（closed way）」
- 2〜2,000個のノードで構成
- ウェイ自身は座標を持たず、ノードのIDを参照する

### Relation（リレーション）
- 複数のNode・Way・Relationを**メンバー**として持つ
- メンバーには**ロール（役割）**を付与可能
- 用途: バス路線、長距離路線、マルチポリゴン、右折禁止など

### タグ（Tag）
- 全要素に `key=value` 形式で属性情報を付与
- 例: `highway=primary`, `name=国道1号`, `oneway=yes`

## ライセンス

### ODbL（Open Database License）1.0
OSMデータのライセンス。主要条件:

1. **帰属表示（Attribution）**: OpenStreetMapへの帰属表示が必須
2. **共有条件（Share-Alike）**: 派生データベースも同じODbLで公開
3. **オープン性維持**: DRMなどの技術的制限をかけてはならない

### 帰属表示の要件
- `© OpenStreetMap contributors` と表示
- `openstreetmap.org/copyright` へのリンクを含める
- ユーザーが自然に目にする位置に配置

| メディア | 配置場所 |
|---------|---------|
| インタラクティブマップ | 地図の隅（折りたたみ可だがアクセス手段が必要） |
| 静止画像 | 画像近辺 |
| 印刷物 | 脚注・謝辞欄にURL |
| ゲーム | スプラッシュ/メニュー/クレジット |

## 日本でのデータ品質

- **都市部**: 道路・鉄道は比較的よく整備されている
- **地方部**: カバレッジにばらつきあり。過去のインポートデータ（1/25000精度）が残る地域もある
- **データソース**: 国土数値情報（KSJ2）インポート、地理院地図のトレーシング、MLIT PLATEAUの建物データなど
