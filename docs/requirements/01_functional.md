# 機能要件定義書

## 1. シミュレーションエンジン

### 1.1 エージェントの種類と属性

#### 共通属性
- **[MUST]** 各エージェントは一意のIDを持つ
- **[MUST]** 各エージェントは `type`（`"zombie"` or `"human"`）を持つ
- **[MUST]** グラフのエッジ上に存在し、`from`、`to`、`progress`（0.0〜1.0）、`edgeDist`で位置を表現
- **[MUST]** `speed`（m/s）と `path`（計算済み経路ノードIDリスト）を持つ

#### ゾンビ
- **[MUST]** デフォルト速度: 1.2 m/s（ゆっくり歩行）
- **[MUST]** 最寄り人間に向かってA*最短経路で移動
- **[MUST]** 最寄り判定はユークリッド距離
- **[SHOULD]** 人間が全滅した場合、移動を停止

#### 人間
- **[MUST]** デフォルト速度: 1.5 m/s（ゾンビより速い）
- **[MUST]** 最寄りゾンビから最も遠い隣接ノードへ逃走（貪欲法）
- **[MUST]** ゾンビ不在時は移動しない
- **[COULD]** 行き止まりでの特別な行動（引き返し等）

### 1.2 移動制約

- **[MUST]** エージェントはグラフのエッジ上のみを移動（道路上に制約）
- **[MUST]** エッジ終端到達時に次のエッジへ遷移（`progress`を0.0にリセット）
- **[MUST]** 無向グラフとして扱う（ゾンビは交通ルールを守らない）
- **[MUST]** 移動量: `deltaTime × speed × speedMultiplier / edgeDist`
- **[SHOULD]** エッジ超過分を次エッジに繰り越し

### 1.3 経路探索

#### ゾンビ（A*）
- **[MUST]** 現在ノード → ターゲット人間ノードのA*最短経路
- **[MUST]** ヒューリスティック: Haversine距離（admissible）
- **[MUST]** 経路未発見時は次に近い人間をターゲット

#### 人間（貪欲法）
- **[MUST]** 隣接ノードのうちゾンビから最遠のノードを選択

#### 再計算
- **[MUST]** 0.5秒ごとに再計算（毎フレームではない）
- **[SHOULD]** エージェント間で再計算タイミングを分散（スパイク軽減）
- **[COULD]** ターゲット未変更時はスキップ

### 1.4 感染判定

- **[MUST]** 毎フレーム実行
- **[MUST]** 距離閾値: 約8m（度数換算 約0.00008度）未満で感染
- **[MUST]** 即座に感染（潜伏期間なし）。`type`をzombieに変更、速度変更
- **[SHOULD]** 同一エッジ・隣接エッジ間のみ比較する最適化
- **[COULD]** 同一フレーム内の連鎖感染防止

### 1.5 開始・終了条件

#### 開始
- **[MUST]** グラフ構築完了済み
- **[MUST]** エージェントがエッジ上にランダム配置済み
- **[MUST]** ユーザーが「開始」ボタン押下

#### 初期配置
- **[MUST]** 指定人数をランダムなエッジ上にランダムな`progress`で配置
- **[SHOULD]** 初期ゾンビと人間の最低距離を確保

#### 終了
- **[MUST]** 全人間がゾンビ化した時点で終了
- **[MUST]** 結果サマリー表示（経過時間等）
- **[COULD]** 時間制限ルール（生存=人間の勝利）

### 1.6 時間管理

- **[MUST]** `requestAnimationFrame`でリアルタイムループ
- **[MUST]** フレームレート非依存の移動（`deltaTime`ベース）
- **[MUST]** 速度倍率（`speedMultiplier`）でシミュレーション速度制御
- **[SHOULD]** `deltaTime`上限（0.1秒）でバックグラウンドタブのワープ防止
- **[COULD]** 速度倍率選択肢: 0.5x / 1x / 2x / 5x

## 2. 地図・データ

### 2.1 地図表示
- **[MUST]** Leaflet.js v1.9.4 + `preferCanvas: true`
- **[MUST]** CartoDB Dark Matterタイル
- **[MUST]** 帰属表示: `© OpenStreetMap contributors © CARTO`
- **[MUST]** 初期位置: 東京（35.6812, 139.7671）、ズーム15
- **[SHOULD]** Geolocation APIで現在地を初期位置に
- **[COULD]** 前回位置をlocalStorageに保存・復元

### 2.2 エリア選択
- **[MUST]** マップクリックでエリア決定 → bbox計算 → Overpass APIリクエスト
- **[MUST]** ローディングインジケーター表示
- **[SHOULD]** 選択エリア範囲を視覚表示（矩形オーバーレイ）
- **[COULD]** 住所検索（Nominatim API）

### 2.3 道路データ範囲
- **[MUST]** bbox半径: 約800m（±0.008度）
- **[SHOULD]** ノード数が少ない場合に警告
- **[COULD]** bbox半径の調整スライダー（400m〜1600m）

### 2.4 対象highwayタグ
- **[MUST]** `residential`, `tertiary`, `secondary`, `primary`, `trunk`, `unclassified`, `living_street`, `pedestrian`, `footway`, `path`, `service`
- **[MUST]** `motorway`は除外

### 2.5 キャッシュ
- **[SHOULD]** localStorageにレスポンスをキャッシュ（有効期限24時間）
- **[COULD]** IndexedDBで大容量対応

### 2.6 エラーハンドリング
- **[MUST]** HTTP 400/429/504のハンドリング
- **[SHOULD]** ミラーサーバーへのフォールバック

## 3. ユーザー操作

### 3.1 シミュレーション制御
- **[MUST]** 開始/一時停止（トグル）/リセットボタン
- **[MUST]** ボタン状態の適切な管理

### 3.2 パラメータ設定
- **[MUST]** 人間数スライダー（10〜200、デフォルト50）
- **[MUST]** ゾンビ数スライダー（1〜20、デフォルト3）
- **[SHOULD]** 速度倍率（0.5x / 1x / 2x / 5x）
- **[SHOULD]** シミュレーション開始前のみ変更可
- **[COULD]** ゾンビ/人間の個別速度調整

### 3.3 実行中インタラクション
- **[COULD]** クリックで追加ゾンビ/人間配置
- **[COULD]** エージェントクリックでカメラ追従
- **[COULD]** ドラッグでバリケード設置

---

## 4. 表示・フィードバック

### 4.1 エージェント表現
- **[MUST]** ゾンビ: `L.circleMarker` 赤系（半径6px）
- **[MUST]** 人間: `L.circleMarker` 青系（半径6px）
- **[SHOULD]** 道路ネットワークを薄い線で描画
- **[COULD]** エージェントの移動軌跡（トレイル）

### 4.2 統計表示
- **[MUST]** 人間数・ゾンビ数・経過時間のリアルタイム表示
- **[SHOULD]** 半透明パネルにオーバーレイ
- **[COULD]** 人口推移の折れ線グラフ

### 4.3 感染フィードバック
- **[MUST]** 色が青→赤に即座に変化
- **[SHOULD]** 感染地点でパルスアニメーション（0.3秒）
- **[COULD]** 効果音（オプション、デフォルトOFF）

### 4.4 終了演出
- **[MUST]** ループ停止 + 終了メッセージ（経過時間、人数）
- **[MUST]** 「もう一度」ボタン
- **[SHOULD]** 最後の1人を強調表示
- **[COULD]** 全ゾンビの勝利演出
