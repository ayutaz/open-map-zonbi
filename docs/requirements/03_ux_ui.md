# UX/UI要件定義書

## 参考プロジェクト

- **Class 3 Outbreak** — Google Maps上のゾンビシミュレーション。色分けドット＋統計パネル
- **Zombietown USA** — 米国全土ゾンビ拡散。シンプルUIとインタラクティブ地図
- **Plague Inc.** — 「読まなくても分かる」ミニマルUI、SIRモデル感染可視化
- **Infection Free Zone** — OSMデータ利用のゾンビサバイバルゲーム

---

## 1. 画面構成・レイアウト

### 画面状態（地図を常に背景に、オーバーレイで切り替え）

#### (A) 初期画面
- **[MUST]** タイトル＋「地図をクリックしてエリア選択」の誘導テキスト（pulse アニメ付き）
- **[SHOULD]** ホラー/サバイバル感のあるフォント
- **[COULD]** ダミーゾンビのデモアニメーション

#### (B) エリア選択中
- **[MUST]** bbox範囲を半透明赤枠で表示 + ローディングスピナー
- **[SHOULD]** スケールバー表示

#### (C) 設定画面
- **[MUST]** 右側にスライドインするパネル（半透明暗色背景）
- **[MUST]** パネル下部に「開始」ボタンを目立つ位置に配置
- **[COULD]** エージェント配置のプレビュー表示

#### (D) シミュレーション実行中
- **[MUST]** 地図全画面 + HUD（上部に統計） + 制御ボタン（下部中央）
- **[SHOULD]** パン/ズーム操作はシミュレーション中も有効

#### (E) 終了画面
- **[MUST]** 赤いフラッシュ → リザルト表示（経過時間、ゾンビ数）をフェードイン
- **[MUST]** 「もう一度」+「エリアを変える」ボタン
- **[COULD]** SNSシェアボタン

### レスポンシブ
- **[MUST]** デスクトップ（1024px以上）で最適化
- **[SHOULD]** タブレット対応（パネル→ボトムシート）
- **[COULD]** スマートフォン対応（パネル→フルスクリーンモーダル）

## 2. ビジュアルデザイン

### カラーパレット
- **[MUST]** 背景: `#1a1a2e`、パネル: `#16213e`
- **[MUST]** ゾンビ: `#e94560`（赤）
- **[MUST]** 人間: `#00d2ff`（シアンブルー）
- **[MUST]** テキスト: `#eee`（主）、`#aaa`（補助）
- **[SHOULD]** 道路: `#2a2a4a`（通常）→ ゾンビ通過後`#3a1a1a`に変色
- **[COULD]** 感染進行で地図全体の色温度を赤方向へ変化

### エージェント表現
- **[MUST]** ゾンビ: 半径4px、不透明度0.9
- **[MUST]** 人間: 半径3px、不透明度0.85
- **[MUST]** ゾンビを人間より大きく表示（脅威の視覚化）
- **[SHOULD]** ゾンビに微小な揺らぎ（±0.5pxランダムオフセット）
- **[SHOULD]** 逃走中の人間に薄い軌跡（trail）

### 道路ネットワーク
- **[MUST]** ポリライン描画（色`#333366`、太さ2px）
- **[SHOULD]** CARTOの道路とは別レイヤーで「シミュレーション対象」を明示
- **[COULD]** ゾンビ通過済みセグメントを暗い赤に変色

### 感染エフェクト
- **[MUST]** 感染地点で半径20pxの円 → 0.3秒で拡大フェードアウト
- **[SHOULD]** 新生ゾンビを0.5秒パルス（拡大縮小2回）
- **[SHOULD]** 連鎖感染時は色をより強い白系に変化
- **[COULD]** 感染時に画面シェイク（2px、0.1秒）

### 侵食感の演出
- **[MUST]** 比率バー（青→赤の侵食）をリアルタイム更新
- **[SHOULD]** ゾンビ占有道路の赤変色
- **[SHOULD]** 最後の1人に白い点滅
- **[COULD]** 四隅から赤いビネットが広がる演出

## 3. インタラクションデザイン

### エリア選択
- **[MUST]** シングルクリックで選択 → bbox自動生成
- **[MUST]** 読み込み中は二重クリック防止
- **[SHOULD]** 道路不足時のフィードバックメッセージ
- **[COULD]** プリセットエリア（東京駅、渋谷、新宿等）

### パラメータ調整UI
- **[MUST]** 人間数スライダー（10〜200、デフォルト50、ステップ10）
- **[MUST]** ゾンビ数スライダー（1〜20、デフォルト3、ステップ1）
- **[SHOULD]** プリセットボタン:
  - 「パニック映画」: 人間100、ゾンビ1
  - 「アウトブレイク」: 人間50、ゾンビ10
  - 「絶望」: 人間30、ゾンビ20
- **[COULD]** シミュレーション速度倍率トグル

### 制御ボタン
- **[MUST]** 一時停止/再開 + リセット（下部中央、フローティングバー）
- **[SHOULD]** ホバーツールチップ
- **[COULD]** キーボードショートカット: Space=一時停止、R=リセット

### 地図操作の共存
- **[MUST]** シミュレーション中もパン/ズーム有効
- **[MUST]** マーカーがクリックイベントを消費しない
- **[SHOULD]** `maxBounds`でエリア外パン制限
- **[COULD]** 「全体表示」ボタン

## 4. 情報表示

### 統計パネル（HUD）
- **[MUST]** 左上配置: 人間数（青丸+数値）、ゾンビ数（赤丸+数値）、比率バー、経過時間（MM:SS）
- **[MUST]** 半透明暗色背景、角丸、パディング12px
- **[MUST]** 数値変化時にスケールアニメーション
- **[SHOULD]** 残り5人以下で人間数を白点滅
- **[SHOULD]** ゾンビ数増加時に明るい赤フラッシュ

### 人口推移グラフ
- **[SHOULD]** ミニグラフ（200×60px）。横軸=時間、縦軸=人数。青/赤エリアチャート
- **[SHOULD]** Canvas APIで描画（外部ライブラリ不使用）
- **[COULD]** 終了時に拡大表示

## 5. 感情設計

### 「面白い」の演出
- **[MUST]** 開始直後2秒間はUI変更なし → 地図上の動きに集中させる
- **[SHOULD]** 最初の感染で統計が動き始める二重フィードバック（視覚+数値）
- **[SHOULD]** 人間の右往左往が見える（「必死に逃げている感」）
- **[COULD]** 50%超で「PANDEMIC」テキスト表示

### 緊張感・臨場感
- **[MUST]** 滑らかな毎フレーム描画更新が最重要
- **[SHOULD]** 残り10人以下でHUD背景を赤味がかった色に変化
- **[SHOULD]** 残り1人に白い円パルスエフェクト（ラストサバイバー強調）

### 全滅時
- **[MUST]** 大フラッシュ → 全ゾンビ停止 → 1秒後リザルトフェードイン
- **[SHOULD]** リザルト: メッセージ + 経過時間 + ミニグラフ最終版
- **[COULD]** 全滅後ゾンビがランダム徘徊（廃墟演出）

### リプレイ促進
- **[MUST]** 「もう一度」ボタンを大きく配置
- **[SHOULD]** リザルト画面にパラメータ変更ショートカット
- **[SHOULD]** 過去記録をlocalStorage保存。自己ベスト更新時ハイライト
- **[COULD]** チャレンジモード、都市間比較の提案テキスト

## 6. アクセシビリティ

### 色覚多様性
- **[MUST]** 赤(`#e94560`)＋シアン(`#00d2ff`)の組み合わせを使用（赤緑色覚異常でも識別可能）
- **[MUST]** 色だけに依存しない（サイズ差＋テキストラベル併記）
- **[SHOULD]** 高コントラストモード（ゾンビ=オレンジ、人間=白）トグル
- **[COULD]** マーカー形状差（四角形、アウトライン等）

### モーション配慮
- **[SHOULD]** `prefers-reduced-motion`で画面シェイク/フラッシュ/パルスを無効化

### キーボード操作
- **[SHOULD]** Space=一時停止、R=リセット、Enter=開始、Escape=パネル閉じ
- **[SHOULD]** Tab操作可能 + フォーカスリング表示
- **[COULD]** `?`キーでショートカット一覧表示

### スクリーンリーダー
- **[COULD]** `aria-label`/`aria-live`を主要動的要素に付与（最低限のアクセシビリティ）

## 設計方針まとめ

1. **地図ファースト** — UIは全てオーバーレイ。地図とエージェントの動きが常に主役
2. **ミニマルHUD** — 読まなくても分かるグラフィック要素優先
3. **段階的緊迫感** — 感染率に連動してUI全体の雰囲気が変化
4. **即座のリプレイ** — 終了→再開始まで1クリック
5. **パフォーマンス優先** — 全エフェクトはCSS/Canvasで軽量実装、60fps維持が最優先
